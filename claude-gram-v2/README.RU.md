# Claude-Gram v2

> [!NOTE]
> Этот проект является форком оригинального репозитория [claude-gram от @ripcats](https://github.com/ripcats/ripcats-marketplace/tree/main/claude-gram), созданным и поддерживаемым разработчиком [@justidev](https://t.me/justidev).

**Claude-Gram v2** – это премиальный хостинг-мост Telegram-канала для [Claude Code](https://claude.ai/code) и Antigravity CLI (`agy`). Он позволяет отправлять и получать тексты, форматированный код, файлы, логи и фотографии прямо из контекста ИИ-агента. Работает как MCP-сервер (Model Context Protocol) поверх stdio, использует `aiogram 3` и включает интерактивное управление профилями, защиту от зомби-процессов и фоновые автообновления.

---

## 🌟 Ключевые возможности

* **Пиксельный маскот «Клодграмик»** – оригинальный персонаж из символов Юникода (создан по мотивам официального логотипа Anthropic) приветствует вас при установке.
* **Адаптивные градиентные баннеры** – красивое приветствие с 24-битным горизонтальным переходом цветов (оранжевый–белый–красный), которое автоматически подстраивается под ширину вашего окна терминала.
* **Интерактивный кросс-платформенный установщик** (`install.sh` / `install.ps1`) – автоматически скачивает все python-библиотеки (`playwright`, `curl_cffi`), ставит chromium и регистрирует фоновые службы под Linux (`systemd`), macOS (`launchd`), Windows (`Task Scheduler`/Автозагрузка) или `PM2`/`nohup`.
* **Автоматические обновления из Git** – раз в 15 минут бот проверяет репозиторий, безопасно подтягивает коммиты (`git reset --hard origin/main`), присылает красивое уведомление в Telegram со списком изменений (changelog коммитов) и перезапускается.
* **Защита от утечки сессий (PTY)** – перехват сигналов `SIGTERM` / `SIGINT` во wrapper-скрипте и использование `control-group` в systemd предотвращают зависание фонового процесса `claude` и ошибку блокировки сессий (`Session ID is already in use`).
* **Управление несколькими аккаунтами** – команды создания (`/login`), переключения (`/switch_account`), бэкапа (`/save_account`) и удаления (`/delete_account`) профилей.
* **Переключение моделей и Effort** – регулируйте тип модели (`/model`) и глубину рассуждений (`/effort`) прямо через встроенную инлайн-клавиатуру Telegram.
* **Сохранение разметки** – входящие и исходящие тексты форматируются с использованием HTML-тегов, сохраняя жирный/курсивный текст, цитаты и код.

## 🚀 Установка

### 1. Автоматический скрипт

Клонируйте проект и запустите скрипт:

#### Linux / macOS:
```bash
chmod +x install.sh
./install.sh
```

#### Windows (Запустите PowerShell от Администратора):
```powershell
Set-ExecutionPolicy Bypass -Scope Process -Force
.\install.ps1
```

Установщик попросит ввести токен бота и ваш Telegram ID, поставит зависимости и настроит службу автозапуска.

## 🤖 Команды бота

| Команда | Описание |
|---|---|
| `/start` | Приветствие и первичная привязка Telegram ID владельца. |
| `/accounts` | Список всех сохраненных профилей и отметка активного. |
| `/login <имя>` | Запуск интерактивной OAuth-авторизации нового профиля. |
| `/save_account` | Резервное копирование учетных данных активного профиля. |
| `/switch_account <имя>` | Переключение на другой сохраненный профиль с перезапуском. |
| `/delete_account <имя>` | Полное удаление файла профиля с сервера. |
| `/model` | Быстрая смена модели (Sonnet, Opus, Haiku) кнопками. |
| `/effort` | Смена уровня рассуждений (low, medium, high). |
| `/usage` | Красивая статистика лимитов использования API и счетов. |
| `/resume` | Выбор и возобновление любой из прошлых сессий Claude Code. |
| `/auto` | Включение/выключение автоматического подтверждения прав. |
| `/close` | Завершение сессии, очистка логов и закрытие форум-топика. |

## 🛠️ Инструменты агента (MCP-сервер)

Эти инструменты предоставляются ИИ-сессии:

| Инструмент | Описание |
|---|---|
| `reply` | Отправить текстовый ответ в Telegram (HTML разметка). |
| `reply_file` / `send_file_to_tg` | Отправить один файл или альбом (логи, скрипты, фото). |
| `reactions` | Автоматическая/ручная emoji-реакция на сообщения. |
| `rename_thread` | Переименование форум-топика текущей сессии. |
| `edit_message` | Изменение ранее отправленного ботом сообщения. |
| `get_history` | Получение локальной истории активного треда. |
