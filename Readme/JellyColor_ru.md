**JellyColor** — модуль для [Heroku](https://github.com/coddrago/Heroku), который позволяет перекрашивать стикеры и эмодзи, накладывать градиенты, а также создавать новые стикеры/эмодзи по текстовым шаблонам с поддержкой пользовательских шрифтов.

Актуальная ветка: **v3.7.0**.

---

## Установка

```bash
.dlm https://raw.githubusercontent.com/justidev-heroku/justi-modules/main/modules/JellyColor.py
```

## Основные возможности

- **Высококачественные градиенты**: Наложение градиента на статические WebP-изображения с использованием HSV Value-яркостного маппинга. Это полностью сохраняет детали, тени, блики и исходный объём стикера, предотвращая затухание цветов (например, красного или синего).
- **Кастомные градиенты**: Возможность добавления собственных градиентов в базу данных с выбором направления (по горизонтали, вертикали, диагонали). Пользовательские градиенты автоматически отображаются в инлайн-меню выбора градиента.
- **Полная асинхронность**: Все ресурсоемкие операции обработки стикеров (распаковка, обработка изображений, упаковка Lottie) вынесены в фоновый режим и не блокируют юзербот.
- **Прямой предпросмотр**: Превью текстовых шаблонов отправляется прямо в активный чат вместо Избранного (`Saved Messages`), с автоудалением после выбора.
- **Автоматическая замена/дозапись (Fallback)**: Если вы пытаетесь создать стикерпак с уже занятым вами именем, модуль автоматически очищает старые стикеры и заменяет их новыми.
- Перекраска статичных (WEBP) и анимированных (TGS) стикеров/эмодзи в один цвет или градиент.
- Интерактивный inline-конструктор `.jt` для создания стикеров/эмодзи из текстовых шаблонов.
- Выбор цвета: 12 обновленных премиальных пресетов, ручной ввод HEX-кода или градиента.
- Поддержка и управление пользовательскими шрифтами (`.ttf`, `.otf`) с сохранением в постоянное хранилище.

## Команды

| Команда | Описание |
|---|---|
| `.j <HEX или градиент>` | Перекрасить стикер, на который сделан ответ |
| `.jc <HEX или градиент>` | Перекрасить и создать новый пак с этим стикером |
| `.jt` | Запустить inline-мастер создания эмодзи из текстовых шаблонов |
| `.jaddfont <название>` | Добавить шрифт (ответом на `.ttf`/`.otf` файл) |
| `.jdelfont <название>` | Удалить пользовательский шрифт |
| `.jfonts` | Список установленных пользовательских шрифтов |
| `.jaddgrad <назв> <HEX,HEX,...> [h/v/d/dr]` | Добавить собственный градиент |
| `.jdelgrad <название>` | Удалить собственный градиент |
| `.jgrads` | Список всех системных и пользовательских градиентов |
| `.jstats` | Статистика операций создания |
| `.jdel <short_name>` | Удалить пак из статистики |
| `.jexport` | Экспортировать статистику в JSON |
