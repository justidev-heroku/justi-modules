**JellyColor** — модуль для [Heroku](https://github.com/coddrago/Heroku), который позволяет перекрашивать стикеры и эмодзи в любой цвет, а также создавать новые стикеры/эмодзи по текстовым шаблонам с поддержкой пользовательских шрифтов.

Актуальная ветка: **v4.6.0**.

---

## Установка

```bash
.dlm https://raw.githubusercontent.com/justidev-heroku/justi-modules/main/modules/JellyColor.py
```

---

## Основные возможности

- **Качественная перекраска**: Перекраска статических (WEBP) и анимированных (TGS) стикеров/эмодзи в один цвет с сохранением деталей, теней, бликов и объёма (яркостный маппинг). Корректно красит fill, stroke и градиентные заливки шейпов.
- **История цветов**: Недавно использованные цвета выводятся отдельным рядом кнопок в меню выбора — повтор в один тап.
- **Авто-название пака**: Кнопка «🎲 Авто» подбирает короткое имя пака автоматически — не нужно придумывать `short_name` вручную.
- **Полная асинхронность**: Все ресурсоёмкие операции обработки стикеров (распаковка, обработка изображений, упаковка Lottie) вынесены в фоновый режим и не блокируют юзербот.
- **Предпросмотр масштаба**: В мастере `.jt` можно настроить масштаб текста и отправить превью первых эмодзи в Избранное перед генерацией.
- **Автоматическая замена/дозапись (Fallback)**: Если вы пытаетесь создать стикерпак с уже занятым вами именем, модуль предлагает пересоздать пак или дописать стикеры в существующий.
- Интерактивный inline-конструктор `.jt` для создания стикеров/эмодзи из текстовых шаблонов.
- Выбор цвета: 12 премиальных пресетов или ручной ввод HEX-кода.
- Поддержка и управление пользовательскими шрифтами (`.ttf`, `.otf`) с сохранением в постоянное хранилище.

## Команды

| Команда | Описание |
|---|---|
| `.j` | Перекрасить стикер/эмодзи, на который сделан ответ (inline-мастер выбора цвета) |
| `.jc <HEX>` | Быстро перекрасить и создать новый пак с этим стикером |
| `.jt` | Запустить inline-мастер создания эмодзи из текстовых шаблонов |
| `.jaddfont <название>` | Добавить шрифт (ответом на `.ttf`/`.otf` файл) |
| `.jdelfont <название>` | Удалить пользовательский шрифт |
| `.jfonts` | Список установленных пользовательских шрифтов |
| `.jstats` | Статистика операций создания |
| `.jdel <short_name>` | Удалить пак из статистики |
| `.jexport` | Экспортировать статистику в JSON |
